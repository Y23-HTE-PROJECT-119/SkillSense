# Python Basics

Python is a high-level, general-purpose programming language widely used for software development, automation, data analysis, and artificial intelligence.

## Variables

Variables allow us to store and reference values in a Python program.

### Variable Declaration

Python variables are created when a value is assigned to a name.

### Variable Naming Rules

Python variable names should follow valid naming conventions and cannot use reserved keywords.

## Data Types

Python provides several built-in data types for representing different kinds of values.

### Integers

Integers represent whole numbers such as 10, 25, and -5.

### Strings

Strings represent sequences of characters such as "Hello" and "Python".
